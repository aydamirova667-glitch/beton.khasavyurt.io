# Сайт «Бетон Солнечное»
## Запуск
Откройте `index.html` двойным щелчком в браузере. Сборка не нужна.
## Что заменить (всё в `js/data.js`)
- **Цены** — массив `GRADES`, поле `price` (₽ за м³). Сейчас стоят ваши цены без НДС: при изменении правьте число после `price:`.
- **Контакты и режим работы** — объект `SITE` в начале файла.
- **Координаты завода** — `mapLat` (широта) и `mapLon` (долгота). Они нужны и для карты, и для расчёта километров. Сейчас стоят координаты вашего завода; если завод переедет, возьмите новые в Яндекс Картах (правый щелчок по месту → скопировать координаты).
- **Поправка на дороги** — `roadFactor` (по умолчанию 1,35). Сверьте с реальными поездками и подберите своё число.
- **Доставка** — `deliveryPerKm` (₽ за 1 км, сейчас тестовое значение), `deliveryPerKmByMixer` (считать за каждый миксер или один раз за заказ), `deliveryBase` (фиксированная подача), `mixerSizes` (объёмы миксеров, сейчас 10 и 7 м³).
- **Рекомендации под задачи** — массив `TASKS`.
- **Логотип** — замените текст в `.logo` в `index.html` на `<img>`.
## Заявки
Форма открывает WhatsApp с готовым текстом. Для отправки на сервер или в Telegram-бот подключите `fetch` в `js/main.js` (место помечено `TODO`).
## Размещение
Загрузите папку на любой хостинг статических сайтов (Netlify, GitHub Pages или обычный хостинг) в корень сайта.

## Доставка по населённым пунктам
В `js/data.js` найдите список `ZONES`. Одна строка — один пункт: `{name:"Название", price:1200},`. Клиент выбирает пункт в калькуляторе и сразу видит цену. `ZONES_PER_MIXER` задаёт, указана цена за один миксер или за весь заказ. Если пункта нет в списке, клиент выбирает «Другой пункт» и доставка считается по километрам. Цены сейчас тестовые.
